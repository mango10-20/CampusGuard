# 仓库地址：`https://github.com/mango10-20/CampusGuard.git`

> 流程：克隆 → 新建个人 feature 分支 → 修改代码 → 推送分支 → 网页提 PR → 评审合并 仓库：CampusGuard，目标合并到 `main`，**暂时未开启分支保护**

## ① 首次克隆（只执行 1 次）

```
# 拉取仓库到本地
git clone https://github.com/mango10-20/CampusGuard.git

# 进入仓库文件夹（必须cd进去！否则git命令报错）
cd CampusGuard
```

## ② 每次开发前，同步 main 最新代码

```
# 拉取远端main最新更新
git pull origin main
```

## ③ 创建自己的功能分支（每人只新建一次，分支名示例 feature/xing_li）

```
# 创建并切换到自己分支，把后面名字换成自己的
git checkout -b feature/xing_li
```

查看当前分支：

```
git branch
```

带`*`的就是当前所在分支。

## ④ 修改文件后，提交并推送到 GitHub 远端

```
# 把所有改动加入暂存
git add .

# 提交，写清楚本次修改内容
git commit -m "完成软件说明书初稿"

# 推送到远端，会自动在GitHub创建feature/xing_li分支
git push origin feature/xing_li
```
